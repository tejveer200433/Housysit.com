# Next.js Project

This project is built with **Next.js**, a modern web framework that makes it easy to create fast websites and applications.  
Think of it as the "engine" that runs this website.

---

## 🛠 How to Run This Project (No Coding Knowledge Needed)

You only need some basic tools installed on your computer:

1. **Install Node.js** (this allows your computer to run JavaScript outside a browser).  
   👉 Download it here: [https://nodejs.org](https://nodejs.org) (choose the LTS version).

2. **Open the project folder** on your computer.  
   - On Windows: Right-click → "Open in Terminal" (or use Command Prompt).  
   - On Mac/Linux: Open Terminal and go to the folder.

3. **Install dependencies (project requirements):**
   ```bash
   npm install
   ````

This will prepare everything the project needs.

4. **Start the project (development mode):**

   ```bash
   npm run dev
   ```

   After a few seconds, you’ll see something like:

   ```
   Local: http://localhost:3000
   ```

   👉 Open that link in your browser to view the website.

---

## 📝 Editing the Website

* The main page is in this file:

  ```
  app/page.js
  ```
* If you change something in that file and save, the website will **auto-refresh** in your browser—no need to restart.

---

## ✨ Features

* Uses **Next.js** to make pages load fast.
* Automatically uses a clean modern font (Geist, from Vercel).
* You can edit text, images, or layout directly in the code, and changes appear instantly.

---

## 🚀 How to Put It Online (Deploy)

The simplest way:

* Go to [Vercel](https://vercel.com) (the company behind Next.js).
* Upload or connect this project’s folder.
* Click **Deploy**.
* You’ll get a live website link (e.g., `https://yourproject.vercel.app`).
